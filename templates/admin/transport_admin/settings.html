Important: Fare Configuration Access Changed

Fare Configuration Now Restricted

As of the latest update, fare configuration (base fares, distance rates, class multipliers, peak pricing, minimum fare, and base currency) has been moved to the Owner / Super Admin settings page only.

What this means for Transport Admins:

  • You can no longer create or modify fare tables via this interface
  • The fare.tables TransportSetting is now governed by Owner/Super Admin role
  • Any changes to fare configuration will be made by Owner or Super Admin
  • You will be notified (via audit log / system notification) when fare changes occur

This Transport Admin settings page remains available for other transport configuration (module toggles, provider settings, booking rules, safety features, etc.). Fare pricing is now a platform-level financial control.
